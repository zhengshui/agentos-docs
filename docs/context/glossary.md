# 术语表

本文维护 AgentOS 的跨项目术语，避免不同工程使用不同语言描述同一能力。

| 术语 | 含义 |
| --- | --- |
| AgentOS | 面向 AI Runtime、Kit、SDK、工具协议和应用宿主的一组工程集合。 |
| AgentKit | 智能体、会话、流式对话和工具调用相关能力。 |
| AppKit | 应用注册、应用事件、宿主调用应用和应用生命周期相关能力。 |
| LLMKit / ModelKit | 模型列表、chat、embedding、ASR、TTS 等模型能力。 |
| ToolKit | AgentOS 中面向工具调用的能力层。 |
| OpenTool | Agent 与工具之间的通用协议和 SDK 生态。 |
| Kernel | 记忆、偏好、RAG、Cron、健康检查和上下文能力。 |
| ChatKit | 可嵌入到 Flutter 或 Web/DOM 应用的聊天 UI 和会话控制组件。 |
| Runtime | Desktop、Server、Embedded、Mobile 等运行环境。 |
| owning repo | 某个能力或 App 的主要负责工程。 |
